MISTAKE BOOK

错题本

面试前优先复习这些高频失分点。

Promise

Promise.race([])

不会 resolve 空数组，而是永久保持 pending。

Promise

Promise.allSettled([])

应立即 fulfilled，结果为 []。

Promise

Promise.any([])

应立即 rejected，错误为包含空 errors 的 AggregateError。

this

debounce 的返回函数

使用箭头函数会捕获外层 this；应返回普通函数取得调用时 this。

Event Loop

while(true) + setTimeout

同步死循环会阻塞事件循环，并且会持续注册大量定时器。

async/await

await 后续执行顺序

await 后续是微任务；与其他 then 回调按实际入队顺序 FIFO 执行。
